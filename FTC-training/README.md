# 5041 FTC Training Hub

Open `index.html` to start the hub. Modules are Reveal.js slide decks and use shared CSS/JavaScript files.

This hub is specific to FIRST Tech Challenge teams supported by 5041 CyBear Robotics and includes modules for foundations, business/leadership, marketing/outreach, drivetrain, manipulators/subsystems, electrical/control systems, and programming/robot control.
